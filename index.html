행운 아이템

    빅데이터 비교 통계

    본 리포트는 입력하신 생년월일 정보를 바탕으로 서버에 저장 없이 브라우저에서만 계산되며, 엔터테인먼트 목적의 프로토타입 결과입니다.

    어떻게 분석하나요?

    1

    정보 입력

    생년월일과 태어난 시간을 입력합니다. 이름과 성별은 선택 사항입니다.

    2

    패턴 매칭

    축적된 사주 유형 데이터에서 유사한 간지(干支) 패턴을 찾아냅니다.

    3

    오행 분석

    목·화·토·금·수 오행 균형을 계산해 에너지 분포를 시각화합니다.

    4

    리포트 생성

    성향, 오늘의 운세, 행운 아이템을 포함한 개인화 리포트를 즉시 보여드립니다.

    자주 묻는 질문

    입력한 정보는 저장되나요?

    아니요. 이 프로토타입은 모든 계산을 브라우저 안에서만 수행하며, 서버로 정보를 전송하거나 저장하지 않습니다.

    실제 사주풀이와 동일한가요?

    아닙니다. 전통 명리학의 정확한 절기·대운 계산 대신, 데모를 위해 간소화된 알고리즘을 사용합니다. 재미로 즐겨주세요.

    태어난 시간을 모르면 어떻게 하나요?

    ‘모름’을 선택하시면 시주(時柱)를 제외한 나머지 정보로 분석 결과를 보여드립니다.
